How it works

Download once. That's the last zip.

PXL fetches each app from its official GitHub release, checks it against its published checksum, and installs it where it belongs.

01

Get PXL

One small download for Mac or Windows. A short tour shows you around.

02

Pick your apps

Press Get. PXL downloads, verifies and installs it. Open it from the sidebar.

03

Forget about updates

New versions install in the background while an app is closed. PXL updates itself too.

One click, start to finish

No unzipping, no dragging to Applications, no hunting for installers. If an app is open when it needs updating, PXL asks it to quit first.
