Features

Studio-grade stems. No studio.

The same kind of model the paid stem sites run, on your own machine and your own GPU.

Four clean stems

Vocals, drums, bass and other, each as its own lossless WAV, lined up sample for sample so they drop straight into a DAW.

VocalsDrumsBassOtherInstrumental

Fast on your own hardware

Demucs (htdemucs) runs through ONNX Runtime, on the Neural Engine and GPU with CoreML on a Mac and DirectML on Windows. No Python to install, no cloud queue.

Any length

Long mixes and DJ sets are split in overlapping chunks and blended back together, so memory stays flat and there are no seams.

Drop anything

MP3, WAV, FLAC, M4A and the audio from video files. Drop a whole folder to split an album.

And a CLI

Script it, batch it, put it in a pipeline.

$ stm split song.mp3
How it works

Three steps. No settings.

The defaults are the good ones. Open the advanced panel only if you want to.

Drop a song

Drag a file or folder onto the window, or use the CLI.

Stm splits it

The model runs locally, chunk by chunk, using your GPU when there is one.

Use the stems

Four WAVs land in a folder next to the song, named and ready for your DAW.

Private by design

It runs on your computer. That's it.

Stm never uploads your music. The model ships with the app and runs offline, so unreleased tracks stay unreleased.
